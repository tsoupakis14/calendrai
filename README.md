# Calendrai

Μίνιμαλ ελληνική εφαρμογή για πλάνο περιεχομένου και εγκρίσεις πελατών. Πλήρες **portfolio demo** με HTML, CSS και JavaScript, χωρίς εξωτερικές βιβλιοθήκες ή backend.

## Άνοιγμα στον υπολογιστή σου

1. Αποσυμπίεσε το project και άνοιξε τον φάκελο `calendrai-project` στο VS Code.
2. Με Node.js 20 ή νεότερο, άνοιξε το Terminal και εκτέλεσε:

```bash
npm start
```

3. Άνοιξε `http://localhost:4173` στον browser.

Δεν χρειάζεται `npm install`: το project δεν έχει dependencies. Εναλλακτικά, άνοιξέ το με το Live Server του VS Code. Μην ανοίγεις το `index.html` με διπλό κλικ: τα JavaScript modules χρειάζονται HTTP server.

## Τι περιλαμβάνει

- Πλάνο με επόμενες αναρτήσεις, προσχέδια και φίλτρα.
- Ημερολόγιο μήνα / εβδομάδας, πλοήγηση στις ημερομηνίες και δημιουργία post πατώντας ημέρα.
- Βιβλιοθήκη περιεχομένου με αναζήτηση και φίλτρα πελάτη, καναλιού και κατάστασης.
- Δημιουργία, επεξεργασία και διαγραφή posts. Ζωντανή προεπισκόπηση κειμένου και εικόνας.
- Ανέβασμα JPG/PNG/WebP έως 8 MB, σμίκρυνση για τοπική αποθήκευση και εικόνες demo.
- Ροή προσχέδιο → προς έγκριση → εγκεκριμένο ή αλλαγές → νέα έγκριση.
- Σχόλια ανά ανάρτηση και προσομοίωση ρόλων designer / πελάτη.
- Τρεις φανταστικοί πελάτες: Nera, Cavo, Vela, με ξεχωριστή προβολή περιεχομένου.
- Τοπική αποθήκευση, χειρισμός σφαλμάτων/γεμάτου χώρου και επαναφορά demo με επιβεβαίωση.
- Responsive εμφάνιση, χειρισμός με πληκτρολόγιο, ονομασμένα πεδία και μηνύματα κατάστασης.

Τα δείγματα παίρνουν ημερομηνίες σχετικές με την ημέρα της πρώτης επίσκεψης. Η επαναφορά δημιουργεί νέο επίκαιρο πλάνο.

## Δοκίμασε τη βασική ροή

1. Πάτησε **Νέο post**, βάλε τίτλο, κείμενο, ημερομηνία και εικόνα.
2. Πάτησε **Για έγκριση**.
3. Άνοιξε το post και πάτησε **Δοκιμή ως πελάτης**.
4. Άφησε σχόλιο και επίλεξε **Ζήτηση αλλαγών** ή **Έγκριση**.
5. Με **Επιστροφή στον designer** επεξεργάσου και στείλε ξανά το post.

Ο κύκλος **Μ** πάνω δεξιά ανοίγει τις ρυθμίσεις demo. Εκεί αλλάζεις ρόλο ή επαναφέρεις τα δείγματα. Μόνο posts που δεν είναι προσχέδια εμφανίζονται στην προβολή του συγκεκριμένου πελάτη. Η επεξεργασία εγκεκριμένου post το επιστρέφει σε προσχέδιο ή το στέλνει εκ νέου για έγκριση.

## Τι σημαίνει portfolio demo

Δεν υπάρχουν πραγματικοί λογαριασμοί, κοινή βάση, email ή αυτόματη δημοσίευση σε social media. Η αλλαγή ρόλου είναι προσομοίωση στον ίδιο browser, όχι μηχανισμός ασφαλούς πρόσβασης. Μην το χρησιμοποιήσεις για εμπιστευτικά στοιχεία πελατών.

Τα δεδομένα αποθηκεύονται στο `localStorage`, με κλειδί `calendrai.demo.v1`, ανά browser και διεύθυνση ιστοσελίδας. Δεν μεταφέρονται από localhost στο live site ούτε μεταξύ συσκευών. Η διαγραφή δεδομένων browser ή η επαναφορά demo τα αφαιρεί. Δεν περιλαμβάνονται στον κώδικα που ανεβάζεις στο GitHub.

Οι έλεγχοι ρόλων προστατεύουν τη ροή του demo, **όχι** τα δεδομένα από κάποιον με πρόσβαση στον browser. Έκδοση παραγωγής χρειάζεται server-side authentication, authorization και αποθήκευση.

## GitHub

Δημιούργησε ένα άδειο repository με όνομα `calendrai`. Από τον φάκελο του project:

```bash
git init
git add .
git commit -m "Build Calendrai portfolio demo"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/calendrai.git
git push -u origin main
```

Αντικατάστησε το `YOUR_USERNAME` με το δικό σου όνομα. Αυτές οι εντολές αφορούν νέο, άδειο repository. Το project δεν περιέχει κωδικούς ή API keys.

## Cloudflare Pages

Σύνδεσε το repository μέσω **Git integration** σε νέο Pages project και όρισε:

| Ρύθμιση | Τιμή |
| --- | --- |
| Framework preset | None |
| Production branch | main |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | Κενό, αν τα αρχεία είναι στη ρίζα του repository |

Το build αντιγράφει μόνο τα δημόσια αρχεία στο `dist`. Οι πηγές, τα tests και οι οδηγίες δεν χρειάζεται να δημοσιευτούν. Κάθε επόμενο push στο συνδεδεμένο branch μπορεί να ενημερώνει την εγκατάσταση, σύμφωνα με τις ρυθμίσεις του Pages project.

Επίσημες οδηγίες: [Git integration](https://developers.cloudflare.com/pages/get-started/git-integration/), [Static HTML](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/), [Build configuration](https://developers.cloudflare.com/pages/configuration/build-configuration/). Έλεγχος οδηγιών: 24/09/2026.

Δεν έχει δημιουργηθεί ή συνδεθεί GitHub repository και δεν έχει γίνει deployment στον δικό σου λογαριασμό Cloudflare. Το πακέτο είναι έτοιμο για αυτά τα βήματα.

## Αρχεία και αλλαγές

```text
index.html          Βασικός σκελετός / metadata
styles.css          Design, χρώματα και responsive διατάξεις
js/app.js           Οθόνες, φόρμες, πλοήγηση και αλληλεπιδράσεις
js/model.js         Δεδομένα, κανόνες εγκρίσεων και δείγματα
js/storage.js       Αποθήκευση και χειρισμός σφαλμάτων
assets/             Favicon και τοπικές εικόνες demo
scripts/serve.mjs   Μικρός local server
scripts/build.mjs   Προετοιμασία φακέλου dist
tests/              Έλεγχοι βασικών κανόνων και αποθήκευσης
_headers            Headers για Cloudflare Pages
```

Τα χρώματα βρίσκονται στην αρχή του `styles.css`. Τα brands και τα αρχικά posts στο `js/model.js`. Η πλοήγηση χρησιμοποιεί hash URLs (`#plan`, `#calendar`, `#content`, `#edit/new`, `#post/ID`, `#approvals`, `#clients`) και δεν χρειάζεται server-side routing.

## Έλεγχοι

```bash
npm test
npm run build
```

Τα tests ελέγχουν όλο τον κύκλο εγκρίσεων, απομόνωση της προβολής πελάτη, invalid input, ημερολόγιο/δίσεκτα έτη και αποτυχίες αποθήκευσης. Για πρακτικό έλεγχο δοκίμασε επιπλέον δημιουργία post, σχόλιο, έγκριση, ανανέωση browser, διαγραφή με ακύρωση και πλοήγηση σε στενή οθόνη.

## Εικόνες

Οι τρεις τοπικές εικόνες δημιουργήθηκαν με το ενσωματωμένο εργαλείο δημιουργίας εικόνων για το συγκεκριμένο demo. Δεν απαιτούν σύνδεση σε εξωτερικό image service. Τα brands και το περιεχόμενο είναι ενδεικτικά. Βλ. `assets/ASSETS.md` για τα prompts.
